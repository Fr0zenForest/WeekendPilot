# 飞控功能构想 — 涵道航模 / 重驾驶乐趣方向

> 状态：构想稿，尚未排期。优先级按"乐趣回报 / 实现成本"主观排序，可随项目演进调整。

## 背景

- **平台演化**：SuperX Nano（C3 + 双 LR1121）承担 RX 解调，从 5V/GND/TX/RX 输出 SBUS/CRSF。本项目原本的"自研接收机"方向退化为**伴侣飞控**：从 SuperX 串口取信道，跑增稳/混控，输出 PWM 给舵机。
- **MCU 候选**：
  - **ESP32-S3**（短期）：复用现有 ElrsRX 软件栈（IMU/Baro/PID/AHRS/PWM/CRSF/WiFi），WiFi WebUI 实时调参是天然优势。最差中断抖动 ~30-50µs，1kHz 增稳过剩，做到 4-8kHz gyro loop 开始吃紧。
  - **STM32F405**（长期）：硬实时（中断延迟 ~120ns，抖动 <5µs），Betaflight/iNav 生态成熟，DShot/动态滤波/EKF 等高级算法有现成参考。代价是整个软件栈重写。
- **设计取向**：放大驾驶乐趣、提升安全余量、解锁手动飞不出来的动作；**不做航拍/测绘类自动飞行**（GPS/RTH/航点等列在最低优先级，仅备查）。
- **目标机型**：涵道、矢量推力、3D 特技。推重比 ≥1，气动易超出经验包线。

## 优先级总览

| 等级 | 类别 | 条目数 | 主旨 |
|---|---|---|---|
| **P1** | 包线保护 | 4 | 你随便造，飞机不会真摔 |
| **P2** | 机动辅助 | 5 | 手动飞不出来的动作，飞控帮你做 |
| **P3** | 选择性自动驾驶 | 3 | 临时锁一个轴，让你专心飞另一个 |
| **P4** | 遥测与黑匣子 | 4 | 飞行体验本身的提升 |

| **Low** | 自动飞行 | 5 | 与"驾驶乐趣"定位冲突，备查 |

## P1 包线保护（安全网，不剥夺操控感）

> 涵道推重比高，新手或老鸟疲劳时容易出包线。这一类是"飞机替你兜底"。

### 1.1 过载限制（G-limit）
拉杆/推杆超过设定 G 值时软化升降舵响应。涵道全速拉杆容易掰机翼蒙皮/胶接结构，这个保护对老飞机寿命也友好。

- 实现要点：IMU 加速度 z 轴 + 姿态投影算"机体法向 G"，用 PT1 平滑后限制升降舵 servo 输出
- 阈值：典型 6-8G 软限，10G 硬限
- 优先级：**P1.A**（纯软件，IMU 已有）

### 1.2 倾角软限制（Horizon mode）
摇杆中位时自我调平到水平，打到边缘时让出全权限。Betaflight Horizon mode 同款行为，新手友好且老鸟特技时能一键关掉。

- 实现要点：现有 Angle Mode 改造，根据摇杆偏转量插值"自稳权重"。摇杆中位 100% 自稳，打满 0% 自稳
- 优先级：**P1.B**（StabModeController 加一个新模式枚举即可）

### 1.3 失速预警/保护
用 IMU + 空速估迎角（无 pitot 也能粗估），临近失速时震杆 + 自动加油门 + 限制升降舵后拉量。

- 实现要点：迎角 α ≈ θ_pitch - γ_flightpath，γ 用 GPS 速度向量或加速度积分。无 GPS 时退化为"低速大仰角 + 法向 G < 1"组合判据
- 输出反馈：油门通道注入 ~5Hz 方波让飞机抖（穷人版震杆），或 CRSF 遥测帧让发射机喇叭报警
- 优先级：**P1.C**（算法稍复杂，建议有 pitot 后再做精确版）

### 1.4 救命键（Panic Recovery）
一键调平 + 油门归中 + 高度保持。涵道飞远了看不清姿态时按一下，2 秒回水平。3D 直升机社区已验证非常救命。

- 实现要点：开关通道触发，进入"姿态归零目标 + 油门吃掉摇杆 + Alt-Hold"复合状态。退出条件：摇杆动了 / 开关复位
- 优先级：**P1.D**（最该先做的一个，算法简单回报巨大）

## P2 机动辅助（飞控混控解锁动作）

> 涵道+矢量推力的飞机有很多"理论上能做、手动配平极难"的动作。

### 2.1 协调转弯
横滚一带，飞控自动配方向舵保持球居中。看着像在飞 1:1 真机。

- 实现要点：横滚率 → 偏航率前馈（公式 `r = g·tan(φ)/V`），叠加侧滑反馈让侧向加速度趋零
- 开关：可单独启用/关闭，不影响其他模式

### 2.2 刀飞辅助（Knife-edge mix）
滚到 90° 后飞控自动用方向舵+升降舵保持高度。手动刀飞 3 个轴同时精细配合极难，混控能让你飞 30 秒。

- 实现要点：检测倾角 |φ| > 60° 时启用混控通道：方向舵 ← 推力补偿，升降舵 ← 横向修正
- 涵道矢量推力机型可用矢量喷口替代方向舵效果更猛

### 2.3 自动倒飞配平
进入倒飞后自动反向升降舵补偿，避免持续推杆。

- 实现要点：检测 |θ_roll| > 90° 时升降舵 trim 反向；过渡区用平滑插值

### 2.4 一键滚转/筋斗
按下扳机自动执行标准动作。能用来"主动作自动 + 手动微调时机"打 8 字滚、四点滚。

- 实现要点：状态机 + 时间序列控制，进入时锁速度/油门，按预设角速度走完一周
- 优先级：娱乐性强，但实现得稳要打磨

### 2.5 悬停辅助（Prop-hang）
推重比 >1 的涵道可做尾立悬停，飞控用 IMU 维持垂直姿态，你只用油门控高度。手动 prop-hang 是绝活级别。

- 实现要点：检测进入悬停区域（仰角 >75°、空速低）后切换控制律——所有舵面变姿态控制器，油门变升力控制器
- 难点：风扰动下保持稳定需要积分项调好，否则会"漂浮"

## P3 选择性自动驾驶（不接管，只锁轴）

> 不是 RTH 那种"飞机自己飞"，而是临时锁住一个轴释放注意力。

### 3.1 高度保持（Alt-Hold）
锁气压高度，专心飞编队/穿越。BMP390 已就位。

- 实现要点：高度误差 → 油门 + 升降舵的 PID 外环。涵道用油门主控更直观
- 启动条件：开关触发的瞬间锁定当前气压高度为 setpoint

### 3.2 航向保持（Heading-Hold）
直线高速通场时锁航向避免侧风偏航。

- 实现要点：偏航角误差 → 方向舵 PID 外环。需要 IMU 偏航估计（Mahony 加 mag 补偿，或纯陀螺积分短期可用）

### 3.3 空速保持
加 pitot（如 MS4525DO，~$10）后让飞机自动维持目标空速。做拉烟通场、固定半径转弯特别稳。

- 实现要点：空速误差 → 油门外环 PID，类似真机自动油门
- 前置：pitot 静态/总压管 + 差压传感器 + 校准曲线

## P4 遥测与黑匣子（飞行体验本身的提升）

### 4.1 变升计 + 音频提示
EdgeTX 上"哔——哔—哔"的爬升/下降提示音。能量管理（高速换高度、高度换速度）时极爽，沿用滑翔机社区玩法。

- 实现要点：BMP390 高度差分得 vario，CRSF VARIO 帧（0x07）回传 EdgeTX
- 已有基础：BMP390 驱动 + CRSF BARO_ALTITUDE 帧已规划

### 4.2 G 力 + 倾角 OSD
FPV 时 OSD 显示实时 G、滚转角、攻角，做特技时一目了然。

- 实现要点：CRSF ATTITUDE 帧（0x1E）+ 自定义 G 帧。EdgeTX widget 显示
- 也可走 MSP 协议接 BetaflightOSD，但需要兼容层

### 4.3 黑匣子（飞行日志）
SD 卡或 flash 存 1kHz 全状态。摔了能复盘"是不是又把摇杆推过头"，调 PID 时看响应曲线。

- 实现要点：复用 Betaflight Blackbox 格式，能直接用 Blackbox Explorer 开。每帧 ~80 字节，1kHz × 5 分钟 ≈ 24MB
- 存储介质：S3 走 SD 卡（SPI），F405 走 SPI flash（W25Q128 ~$1，16MB）
- **优先级建议提前**：调参提速 10 倍，目前 PID 全靠手感，有 log 就是科学实验

### 4.4 链路质量 + RSSI 双向
CRSF 已天然支持，沿用 ElrsRX 已有的遥测帧逻辑反向接 SuperX。

- 实现要点：从 SuperX 收 LinkStatistics（0x14）转发给增稳供链路降级判据用
- 已部分实现：现有 link_ok 标志已接入 StabModeController DEGRADED 分支

## P5 涵道航模特有玩法

### 5.1 矢量推力混控
涵道带可动喷口（V-tail / 喷口偏转）时，**只在低速启用矢量**（高速靠气动舵面），像 F-22 那样。

- 实现要点：空速阈值切换（如 <15m/s 启用矢量），过渡区线性混合。矢量舵机和气动舵机**通道独立**，飞控按当前控制律分配
- 难点：切换时机会突变姿态响应，需要 fade-in/out

### 5.2 双涵道差速推力
双发机型用油门差速辅助偏航，飞控自动混控。F-18、苏霍伊双发涵道做超机动靠的就是这个。

- 实现要点：偏航需求 → 左右油门差值。需要双 ESC 通道独立控制
- 注意：差速过大会损失总推力，要带功率守恒约束

### 5.3 进气道保护（喘振防护）
低速大迎角时涵道易喘振（进气分离），飞控可在迎角超阈值时强制降转速避免炸涵道。**真·涵道特色保护**。

- 实现要点：迎角 + 转速 + 油门组合判据。喘振区域查表，进入区域强制油门下限
- 难点：每个机型涵道喘振区不同，需机型预设或现场学习

### 5.4 过失速机动（Post-stall maneuvers）
眼镜蛇、Kulbit 这类动作，飞控帮你切换"气动控制"和"姿态控制"模式。过失速段直接靠矢量推力指向，回流速后切回常规。

- 实现要点：空速门限切换控制律。气动模式下舵面是主，姿态模式下矢量是主
- 前置：5.1 矢量混控 + 5.3 进气道保护

## P6 调参/上位机

### 6.1 WiFi WebUI 实时调参（S3 路线）
**已有基础**：现有 ElrsRX WebUI POST 解析 + 双缓冲 reloadConfig 链路。延展到飞控就是加 PID 曲线、混控权重、模式开关、黑匣子下载。

- 优势：边飞边调（地面站 wifi 或手机热点），Betaflight 都做不到
- 限制：S3 才行，F405 路线需外挂 ESP01 或走 USB CDC

### 6.2 USB CDC + 地面站（F405 路线，备选）
传统飞控套路：USB 插上后跑 Betaflight Configurator/iNav Configurator 风格协议（MSP）。

- 实现要点：MSP v2 协议子集 + Web 版地面站（开源参考 Betaflight Configurator 浏览器版）
- 优先级低：仅当迁 F405 时再考虑

## Low Priority — 自动飞行（与定位冲突，仅备查）

> 这些功能与"重驾驶乐趣"取向冲突——飞机自己飞了你玩什么。但记录在案，未来若做长航时巡航或新手训练机时可启用。

### L.1 GPS 定位 + 速度向量
- 加 GPS 模块（u-blox NEO-M9N ~$15）
- 解锁：地速、轨迹角、回家方向显示
- 副作用：可作为失速保护（§1.3）的速度源、空速保持（§3.3）的退化方案

### L.2 自动返航（RTH）
- 信号丢失/低电压触发，按 GPS 航向回起飞点
- 涵道航模通常没航拍那么"宝贵"，且 RTH 路径上撞树/电线风险高，建议低优先级

### L.3 航点飞行
- 预设航点序列自动飞，需要 GPS + 高度 + 空速 + 完整外环控制器
- 完全是测绘党玩法，跟驾驶乐趣无关

### L.4 图传 OSD 集成
- VTX/MSP DisplayPort/HD 数字图传协议接入
- 涵道航模视距飞为主，FPV 不是核心。若做 FPV 改装再说

### L.5 自稳悬停（多旋翼式 Position-Hold）
- 加 GPS + 光流（PMW3901）+ 测距（VL53L1X）
- 多旋翼悬停体验照搬到固定翼/涵道意义不大（涵道靠 prop-hang 有更帅的玩法，§2.5）

## 实现路线建议

### 阶段 0（现状）
- ✅ 增稳基础（Off / Angle / Rate）
- ✅ IMU + Baro 硬件接入
- ✅ WebUI 实时调参链路
- ⏸️ 硬件验证（等外部电源）

### 阶段 1（最快回报，1-2 周）
1. **Panic Recovery (P1.D)**：算法最简单，回报最大
2. **G-limit (P1.A)**：纯加法，加在 PID 输出后
3. **Horizon Mode (P1.B)**：现有模式控制器加一个枚举
4. **黑匣子 (P4.3)**：调参基础设施，提前做收益最高

### 阶段 2（涵道特色，平台无关）
5. **Alt-Hold (P3.1)**：BMP390 已就位
6. **变升计音效 (P4.1)**：CRSF 帧扩展
7. **协调转弯 (P2.1)**：纯混控
8. **刀飞辅助 (P2.2)**：纯混控

### 阶段 3（机型相关）
9. **悬停辅助 (P2.5)**：装上推重比 >1 的实机后再调
10. **矢量推力混控 (P5.1)**：装上矢量喷口后再做
11. **进气道保护 (P5.3)**：装上转速传感器/电流传感器后做

### 阶段 4（平台抉择点）
12. 评估 S3 抖动是否够用：跑 1kHz Mahony + cascade PID + biquad notch，看实测最差 latency
13. 不够 → 迁 F405，开始 Betaflight 化：DShot、动态滤波、4-8kHz gyro loop
14. 够用 → 继续 S3 路线，主攻 WiFi WebUI 调参体验
